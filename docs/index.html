chess-digest

chess-digest reviews your recent chess.com games. It downloads them, runs Stockfish on every move, asks Claude which mistakes you keep repeating, and writes a short report with board diagrams and links to practice material.

Example digests Source on GitHub

What you get

  • Your record, accuracy and blunders per game.
  • Three to five recurring problems. Each one has an explanation, a way to fix it, and positions from your own games.
  • Puzzles and articles for each problem: Lichess puzzle themes, Lichess practice, Wikipedia.
  • Tables of your openings and of mistakes by game phase, plus every game with a link back to chess.com.

How it works

  1. Games come from the chess.com Published-Data API. You don't need to log in.
  2. Stockfish evaluates every position. A move counts as a mistake when your winning chances drop by 20 points, and as a blunder at 30.
  3. The worst mistakes and your stats go to Claude in one request. Claude can only choose from a fixed list of themes and from mistakes that really happened, so it can't make up positions or links.
  4. The report is a single HTML file. Each board is an inline SVG of about 2 KB.

Set it up

You need Docker Desktop, git and an Anthropic API key.

git clone https://github.com/VladKhomich/chess-digest.git
cd chess-digest
cp .env.example .env        # add ANTHROPIC_API_KEY and CHESSCOM_USER
docker compose build
docker compose run --rm digest --games 30

The report lands in out/. On Windows you can load chess.ps1 from your PowerShell profile and use shorter commands:

. "C:\path\to\chess-digest\chess.ps1"   # in $PROFILE

chess analyse -g 10      # last 10 games
chess analyse --week     # everything from the last 7 days
chess open               # reopen the latest report

A game that went into an earlier report is skipped next time. Add --all to include it again.

Publish your own reports

Fork the repo and turn on GitHub Pages for the docs folder of main. Then run chess analyse --week --publish. It adds the report to docs/digests/, commits only that folder and pushes. Published pages hide your opponents' usernames and ask search engines not to index them.

Cost

Stockfish runs on your machine. Each report makes one Claude Sonnet call. That's usually a few cents, and a week of games rarely goes past 25 cents.
